Executive Overview

Problem Statement & Strategic AI Solution

Traditional NIDS Limitations
  • Static Rule Signatures: Fails against mutated zero-day network threats.
  • High Alarm Fatigue: SOC analysts flooded with false positives daily.
  • Bandwidth Bottlenecks: Manual log review cannot scale with modern gigabit networks.
  • Response Lag: Static batch analysis delays threat containment by hours.
AI-NIDS Intelligent Solution
  • ML Pattern Learning: Random Forest & Decision Tree models with 78% accuracy.
  • 96.68% Attack Precision: High fidelity classification eliminates SOC false alarms.
  • Sub-Second WebSocket Stream: Continuous real-time traffic monitoring & verdict push.
  • Automated Alert Lifecycle: CRITICAL, HIGH, and MEDIUM severity auto-scoring.

Data Pipeline

NSL-KDD Benchmark Dataset & 20-Feature Selector

NSL-KDD Dataset Characteristics
  • Solved Duplication: Fixes KDD'99 duplicate records to prevent classifier bias.
  • Dataset Volumes: 125,973 training records; 22,544 test set records.
  • Attack Categories: DoS, Probe, R2L (Remote to Local), and U2R (User to Root).
Top Selected Features (Out of 41 Raw)
  • Bytes & Protocols: src_bytes, dst_bytes, protocol_type (TCP/UDP/ICMP).
  • Connection Statistics: count, srv_count, logged_in status.
  • Error & Service Rates: serror_rate, srv_serror_rate, same_srv_rate.
  • Host Statistics: dst_host_srv_count, dst_host_same_srv_rate.
Machine Learning

Model Architecture & Supervised Classifiers

Random Forest Classifier (Primary Model)
  • Ensemble Architecture: Bagging trees over random feature subsets.
  • Overfitting Resistance: Superior generalization on unseen test traffic.
  • Feature Importances: Gini impurity scoring highlights top connection vectors.
  • Verdict: Selected as primary production model.
Decision Tree Classifier (Baseline Model)
  • Recursive Splitting: Binary decisions based on entropy & information gain.
  • Ultra-Fast Execution: Sub-millisecond single-vector inference speed.
  • Rule Interpretability: Decision branches can be audited by analysts.
  • Verdict: Evaluated as fast comparison baseline.

Real-Time Engine

WebSocket Traffic Stream & Severity Auto-Scoring

WebSocket Endpoint (`/ws`)
  • Full-Duplex Push: Emits live JSON telemetry frames every 2.0 seconds.
  • Async Manager: Handles concurrent SOC analyst dashboard connections.
  • Automatic DB Recording: Stores packet history with confidence metrics.
Severity Scoring Engine
  • CRITICAL (Red): Verdict ATTACK with Confidence ≥ 90%.
  • HIGH (Amber): Verdict ATTACK with Confidence ≥ 80%.
  • MEDIUM / LOW: Verdict ATTACK with Confidence < 80%.
  • NORMAL (Green): Legitimate non-attack network flow.
